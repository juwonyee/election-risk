# election-risk

This extension adds four Agent Skills in `skills/`: `profit-structure`, `candidate-positions`,
`prediction-markets` and `election-risk`. Read the matching `skills/<name>/SKILL.md` before doing that kind of
task, and run the engine as `python3 skills/<name>/scripts/erisk.py` from the user's working directory.
Start with `skills/election-risk/SKILL.md` when the user asks what the Nov 3, 2026 US elections could mean
for a company.
